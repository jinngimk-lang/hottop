# Hottop Agent Instructions

This repository is a persistent hot-topic brand creative system. It must work for **any current product**, not only historical examples such as InkClawAgent.

## Mandatory creative entrypoint

For any request to discover a live hotspot and generate an image/video/social asset, read in this order:

1. `PROJECT.md`
2. `STATUS.md`
3. `docs/creative/REALTIME_HOTSPOT_PRODUCT_BRIDGE_AGENT_GUIDE.md`
4. `skills/portable-creative-logic/SKILL.md`
5. `integrations/portable-creative-logic-library.yml`
6. `skills/creative-reference-memory/SKILL.md`
7. `skills/brand-metaphor-creative/SKILL.md`

## Core operating rules

- **Fresh user heat first.** Do not treat an official announcement alone as proof of a hotspot. Find current user search/ranking/community/comment/remix signals, then verify facts separately.
- **Fresh run every time.** Re-resolve product, hotspot, bridge, medium, format and preflight for each new asset.
- **Separate source event from derivative meme.** Find the exact current question, number, action, object, reaction phrase or relationship users are repeating now.
- **Product truth before joke.** Map a real current capability/job-to-be-done before inserting the product.
- **Product must change the story outcome.** If an unrelated brand can replace it without changing the scene, reject the concept.
- **Borrow mechanism, not skin.** Do not copy protected characters, exact frames, public-figure likenesses, proprietary UI/trade dress, or historical Hottop visual shells.
- **Never just swap product names.** When the promoted product changes, re-run product-role mapping from zero.
- **Do not default to four panels, cows, robots, cinema, rough 3D, or any prior successful style.** Format and medium follow the current hotspot/product bridge.
- **Hotspot-native hook first, product consequence second, light attribution last.** Avoid brand-first cold opens and feature-grid endings unless the brief specifically requires them.
- **Finance is research-first, not advice-first.** Current market questions may become research/analysis workflows, but never fabricate valuation conclusions, target prices, guarantees or personalized buy/sell instructions.
- **Run generation preflight before final generation.** Research observation should normally be within 6 hours; selected hotspot publication should normally be within 7 days when known, with stricter same-day handling for markets/breaking news/sports.
- **Reject stale-template contamination.** If a generator inherits old Hottop characters, numbers, scenes, layouts or punchlines that were not selected for the current run, discard and restart from a clean prompt/reference.

## Learning after publishing

Persist learning at the right layer:

- concrete success/failure/user feedback/platform result → `integrations/creative-reference-library.yml`;
- product-independent hook/bridge/product-role lesson → `integrations/portable-creative-logic-library.yml`;
- hotspot discovery/research process improvement → `docs/creative/REALTIME_HOTSPOT_PRODUCT_BRIDGE_AGENT_GUIDE.md` or a research record.

Do not convert one successful asset into a permanent template.

## Core doctrine

**Persist mechanisms, not mascots. Persist product roles, not product names. Persist search language, not yesterday's headline.**
