# hottop

Hot-topic meme research and creative-brief pipeline for product marketing.

The repository turns current cultural/tech/film/internet trends into structured four-panel meme briefs. A product such as **InkClawAgent** is mapped onto the strongest “solver / breaker / winner” role in the trend’s conflict, while a user-selected competing tool or old workflow can be mapped onto the obstacle/antagonist role.

> This is a satire/creative system, not a factual benchmark engine. Comparative factual claims must be backed by evidence; otherwise the output should stay clearly comedic, subjective, or metaphorical.

The full pipeline, collectors, MCP config, reusable agent skill, and automation are being built in this repository.
